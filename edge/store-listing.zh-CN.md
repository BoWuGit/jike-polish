## Description

复制以下正文到 Description：

```text
阅赏是一款专为即刻 Web（web.okjike.com）设计的开源、非官方 Microsoft Edge 扩展，用于改善桌面端阅读、转发内容预览和图片浏览体验。

主要功能：
• 优化字体、字重、行高、间距和页面布局，让信息流与动态详情更适合桌面阅读。
• 增强转发/引用卡片：悬停或键盘聚焦时展开被折叠的正文，并在卡片中补充原帖图片、视频和链接预览；超长内容可在卡片内滚动。
• 提供用户资料悬浮卡片：在 @用户 链接上悬停即可查看头像、昵称、简介、地区、行业标签及关注数据，并可主动关注或取消关注。
• 增强网站原生图片灯箱：支持 1×–6× 缩放、滚轮、双击、拖拽平移、工具栏按钮和键盘操作，切换图片时自动还原。
• 适配浅色和深色界面，并尽量保持目标网站原有的布局、圆角和交互方式。
• 点击工具栏中的扩展图标可打开完整的离线功能演示，使用本地虚构内容体验排版对比、转发媒体、用户卡片和图片灯箱，无需账号或网络。

扩展没有自有账号。离线演示无需登录；实际网站集成仅在 web.okjike.com 上运行，而该第三方网站目前要求使用其手机 App 扫码登录。扩展不会修改其他网站，不包含广告、分析、遥测或用户追踪，也不会把登录信息或页面内容发送给开发者。

本项目与目标网站的运营方不存在隶属、授权、认可或合作关系。源代码、隐私政策和问题反馈渠道均可在项目网站查看。
```
