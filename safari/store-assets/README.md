# Safari 商店截图

`screenshots/` 中的图片为 macOS App Store 可用的 2880×1800 PNG，均来自 Safari 中的公开即刻页面：

- `safari-user-card.png`：用户资料悬浮卡片

截图前仅保留“即刻 Web 美化”的页面效果，隐藏其他扩展注入的界面。公开页面内容可能变化，正式提交新版本前应重新检查截图。

商店图片和仓库中不得包含登录 Token、开发者证书、App Store Connect API Key、Provisioning Profile 或其他凭据。
