# Chrome Web Store 截图

`screenshots/` 中的图片为 Chrome Web Store 可用的 1280×800 PNG，均来自 Chrome 中已登录的即刻页面，并在左上角使用红色标签说明功能：

- `chrome-user-hover-card.png`：转发详情与用户资料悬浮卡片
- `chrome-lightbox-multi-zoom.png`：图片灯箱多级缩放控制

截图时仅保留“清阅 Web 助手”和目标网页自身的界面。页面内容可能变化，正式提交新版本前应重新检查截图。

商店图片和仓库中不得包含登录 Token、Chrome Web Store OAuth 凭据或其他敏感信息。
