# 隐私政策 / Privacy Policy

最后更新：2026 年 7 月 24 日

“清阅”是一款开源、非官方的 Safari Web Extension，仅在 `https://web.okjike.com/` 页面上运行。

## 数据处理

- 本扩展不会向开发者或开发者控制的服务器收集、上传、出售或共享任何个人数据。
- 为提供用户悬浮卡片等增强功能，本扩展可能在用户设备上读取即刻网页版已保存的登录令牌，并仅将其发送至即刻官方 API。令牌不会发送给开发者或其他第三方，也不会由本扩展另行存储。
- 页面内容和扩展设置仅在用户设备及当前浏览器环境中处理。
- 本扩展不包含广告、分析、遥测或用户追踪功能。

## 第三方服务

用户访问目标网站以及向其官方 API 发出的请求，受该网站自身的服务条款和隐私政策约束。“清阅”与目标网站的运营方不存在隶属、授权或合作关系。

## 联系方式

如对本隐私政策有疑问，请通过 GitHub Issues 联系：
https://github.com/BoWuGit/jike-polish/issues

---

“Jike Polish” is an open-source, unofficial Safari Web Extension that runs only on `https://web.okjike.com/`.

The extension does not collect, upload, sell, or share personal data with the developer or any developer-controlled server. To provide enhancements such as hover user cards, it may read authentication tokens already stored by the Jike website on the user’s device and send them only to Jike’s official API. These tokens are never sent to the developer or another third party and are not separately retained by the extension.

Page content and extension settings are processed locally. The extension contains no advertising, analytics, telemetry, or user tracking. Use of the Jike website and official API is governed by Jike’s own terms and privacy policy. This project is not affiliated with, endorsed by, or sponsored by Jike.
