# App Review Notes

This is an open-source, unofficial Safari Web Extension for `web.okjike.com`. The extension does not implement or control Jike authentication.

Testing steps:

1. Launch the containing app.
2. Open Safari Settings, select Extensions, enable “即刻 Web 美化”, and allow access to `web.okjike.com`.
3. Open this public page to test repost-media enhancement and image-lightbox zoom controls: <https://web.okjike.com/u/34953782-20EA-4675-9108-FD005F127C53/repost/6a3c111c3d621d7862d5f30c>
4. Open this public page to view an `@user` link: <https://web.okjike.com/u/28e960ee-9e3a-45bb-bee3-d859b34416c1/repost/69c14cecc5a1d4e6497efb7d>

No demo account is required to review the extension's public-page functionality. The optional enhanced user hover card uses authenticated profile data from the third-party Jike service. Jike Web supports sign-in only through a short-lived QR code scanned with the official Jike mobile app; it does not offer reusable username/password credentials. The authenticated hover-card result is shown in the submitted App Store screenshot, and review can be completed without signing in.

The extension sends no data to the developer and is not affiliated with Jike.
